# ANTIGRAVITY SKILLS — Lightning Globe

## Skill 01: Repository Recon
Önce repository'yi anla, sonra kod yaz.

## Skill 02: Provider Adapter
Harici lightning API payload'unu domain modeline çevir.

## Skill 03: Data Validation
Coordinates/time/numeric fields doğrula; malformed record'u izole et.

## Skill 04: Deduplication
Aynı lightning event'i ikinci kez gösterme.

## Skill 05: Temporal Windowing
Recent activity pencereleri üret.

## Skill 06: Spatial Clustering
Haversine + spatial clustering ile yakın lightning olaylarını grupla.

## Skill 07: Dateline Handling
±180 longitude geçişlerini doğru ele al.

## Skill 08: Activity Scoring
Cluster'ın sunum önceliğini hesapla.

## Skill 09: Growth Detection
Son zaman dilimlerine göre aktivite artışını hesapla.

## Skill 10: Presentation Queue
Kamera için priority queue yönet.

## Skill 11: Camera Director
Camera intent üret; UI'dan bağımsız state machine uygula.

## Skill 12: Geographic Framing
Cluster boyutuna göre global/continental/regional/local framing seç.

## Skill 13: Cinematic Transition
Teleport yerine kontrollü easing/approach uygula.

## Skill 14: Lightning FX
Kısa ömürlü flash/glow/ring efektleri üret ve temizle.

## Skill 15: Cluster Visualization
Tek olay ile yoğun fırtına aktivitesini farklı görsel ağırlıkta göster.

## Skill 16: Live Health
LIVE/STale/OFFLINE durumlarını doğru yönet.

## Skill 17: Demo Injection
Gerçek pipeline ile aynı akıştan synthetic lightning üret.

## Skill 18: Performance Audit
Frame time, draw calls, objects, effects, event count ölç.

## Skill 19: Accessibility
Reduced motion + keyboard + text alternatives.

## Skill 20: Visual QA
Kamera target, marker position, dateline, poles, clipping ve effect cleanup kontrol et.

## Skill 21: Scientific Honesty
Görsel intensity/footprint'i gerçek enerji/hasar modeli gibi sunma.

## Skill 22: Dependency Discipline
Gereksiz kütüphane ekleme.

## Skill 23: Failure Recovery
Provider hatasında cache'i koru, retry/backoff kullan.

## Skill 24: Incremental Delivery
Her faz sonunda çalışan build bırak.

## Skill 25: Agent Self-Review
Done demeden:
- build,
- tests,
- runtime,
- performance,
- architecture

kontrol et.
